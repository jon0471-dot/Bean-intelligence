# NIIKI — Creative Production (3D / Animation / Motion / VFX)

**Status: PLANNED (M51). There is NO implementation in this repository today.**

This document is the recorded technical direction for the owner-approved M51
milestone. No NIIKI code, UI, model integration or capability exists — the
BEAN AUTOBOTS catalogue deliberately contains no NIIKI capability and no
template claims motion-design execution. BEAN must never pretend.

## 1. Planned purpose and responsibilities

A creative production system for 3D scene creation, geometry, materials,
lighting, animation, motion graphics, particles, VFX, compositing and
editable project export.

## 2. Planned architecture (technical direction)

- Deterministic procedural 3D/motion pipeline where genuinely supported
  (local rendering of procedural scenes; no fabricated "generative 3D").
- Evaluation of real, appropriately licensed models/tools before any
  generative capability is claimed — acceptance evidence required.
- Editable project export (scene graph persisted owner-scoped; formats
  chosen for real interoperability, not marketing).
- Integration through the existing orchestration/delegation contracts
  (RIISHE/AUTOBOTS delegate to NIIKI lanes the same way LAXII/JAZMII are
  delegated to today — durable jobs, gates, receipts).

## 4–8. Model/provider integration, contracts, tools, data, workflow

## 9. Tests and verification

To be written with the implementation; deterministic render units for

## 10. Failure handling

Planned: honest per-stage render/generation states; unsupported operations
refused with the real reason.

## 11. Current implemented capabilities

**None.** No 3D, animation, motion-graphics, particles, VFX or compositing
capability exists in BEAN today. JAZMII's video jobs and director
